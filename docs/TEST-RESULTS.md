## Verified environment

This runs PostgreSQL SQL/constraints/transactions, but it is **not a native network PostgreSQL server**. ## Retrieval interpretation
The 50 seeded cases contain five variations of each of ten incident families. The ten queries are labelled using those families. High scores on this small, repetitive synthetic set demonstrate pipeline function, not operational accuracy. Evaluation uses the seeded set before E2E-created cases are indexed. Full query/incident IDs and per-query metrics are in retrieval-results.json. No confidence percentage is attached to an individual search result.
